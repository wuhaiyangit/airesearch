## 1. 摘要与核心贡献

### 研究问题

推荐系统在实际应用中通常采用多阶段架构：召回（Retrieval）→ 粗排（Ranking）→ 精排（Reranking）。然而，现有基于大语言模型（LLM）的推荐研究大多聚焦于召回和排序阶段，对重排（Reranking）阶段的关注严重不足。重排阶段直接影响最终呈现给用户的推荐结果质量，因此这一研究空白值得深入探索。

除此之外，现有的 LLM 推荐方法存在三个关键局限：第一，大多数方法仅在零样本或少样本设置下使用 LLM，未能充分利用强化学习（RL）和高质量推理数据来激发 LLM 的推理能力；第二，物品通常使用非语义 ID（Non-semantic IDs）表示，在拥有数十亿物品标识符的工业系统中面临严重的可扩展性挑战；第三，重排阶段被广泛忽视，而这正是精炼最终推荐结果的关键环节。

### 动机

随着 LLM 在自然语言处理领域取得的巨大成功，研究者开始探索将其应用于推荐系统的可能性。然而，将 LLM 成功迁移至推荐场景面临以下核心挑战：如何在保持 LLM 强大语言理解能力的同时，使其能够处理推荐场景特有的海量物品标识？如何激发 LLM 的推理能力，使其能够像人类专家一样进行多步骤的购买意图推理？如何在强化学习框架下优化重排目标，同时避免奖励黑客（Reward Hacking）行为？

GR2 论文的核心动机正是解决上述挑战，构建一个能够充分发挥 LLM 推理能力的端到端生成式重排系统。

### 方法概要

GR2 提出三阶段训练管道：第一阶段使用基于 RQ-VAE 的语义 ID 分词器（Tokenizer），将非语义物品 ID 编码为语义 ID（Semantic ID），并通过中期训练（Mid-Training）使 LLM 理解这些离散化的语义表示；第二阶段利用更大规模的教师 LLM（Qwen3-32B）生成高质量推理轨迹，通过精心设计的提示工程和拒绝采样（Rejection Sampling）过滤噪声轨迹，然后进行监督微调（SFT）；第三阶段采用 DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）算法，结合专门为重排设计的新型奖励函数进行强化学习优化。

### 主要结果

在 Amazon Beauty 和 Sports 两个真实数据集上的实验表明，GR2 始终超越领先的 OneRec-Think 基线：在 Recall@5 上提升 2.4%，在 NDCG@5 上提升 1.3%。消融实验证实，高级推理轨迹在所有指标上都能带来显著的性能提升。

### 核心贡献

1. **首个专注于重排阶段的 LLM 推荐框架**：不同于以往主要适配 LLM 用于召回和排序阶段的研究，GR2 首次系统地研究并建立了针对推荐系统重排阶段的 LLM 设计原则。

2. **≥99% 唯一性的语义 ID 生成方法**：通过 EMA 更新、随机最后层级等五种互补技术，有效解决了 RQ-VAE 训练中的码本坍缩（Codebook Collapse）问题，实现了语义 ID 的高唯一性。

3. **面向重排的推理轨迹生成与 SFT**：设计了专门针对重排场景的提示模板，结合分层物品信息和拒绝采样技术，生成了高质量、可验证的推理轨迹用于模型微调。

4. **针对重排的 DAPO 强化学习优化**：重新设计 DAPO 的奖励函数，针对重排任务的特点引入条件可验证奖励，有效缓解奖励黑客问题，实现可扩展的 RL 监督。

## 2. 业界进展与相关工作

### 领域发展脉络

生成式推荐系统的发展历程可以追溯到将推荐任务统一建模为序列生成问题的早期探索。TIGER（Rajput et al., 2023）开创性地引入语义 ID（Semantic ID）技术，通过 RQ-VAE 将物品表征离散化，使自回归推荐无需大规模嵌入表成为可能。这一突破为后续研究奠定了重要基础。

在此基础上，OneRec（Zhou et al., 2025b）提出统一的文本到文本框架，将多个推荐任务统一到单一的 LLM 生成范式中。OneRec-Think（Liu et al., 2025）进一步引入显式推理轨迹，展示了链式思维风格的中间推理可以提升推荐的准确性和鲁棒性。PLUM（He et al., 2025）则采用类似的中期训练策略（Continued Pre-training），使预训练 LLM 与推荐领域对齐。

### 主要技术路线对比

**技术路线一：语义 ID + 自回归生成**

代表工作：TIGER、OneRec 系列

核心思想：将物品表示为离散化的语义 ID 序列，通过自回归模型直接生成下一个物品的语义 ID，从而实现生成式推荐。这种方法避免了传统协同过滤的大规模嵌入表问题，具有良好的可扩展性。

优势：物品表示紧凑、可离线路由、支持新物品泛化

局限：语义 ID 的质量和唯一性难以保证，重排能力受限

**技术路线二：LLM + 提示工程**

代表工作：P5（Geng et al., 2022）、各类 In-Context Learning 方法

核心思想：将推荐任务转化为自然语言任务，通过精心设计的提示模板引导 LLM 进行推荐预测。

优势：利用 LLM 的世界知识和语言理解能力

局限：零样本能力有限，推理能力未被充分激发

**技术路线三：LLM + 强化学习优化**

代表工作：GRPO、ReaRank、GR2

核心思想：通过 RL 方法优化 LLM 的推理和决策能力，使用可验证奖励进行策略优化。

优势：能够直接优化下游指标，推理能力强

局限：奖励设计困难，易出现奖励黑客

### 本文定位

GR2 在技术路线一的基础上，融合了技术路线三的 RL 优化思路，首次将生成式重排任务作为核心研究对象，提出完整的三阶段训练管道。其创新点在于：第一，系统解决了语义 ID 生成中的码本坍缩问题，达到 ≥99% 唯一性；第二，设计了专门面向重排的推理轨迹生成框架；第三，针对重排任务重新设计了 DAPO 奖励函数，有效缓解奖励黑客。

## 3. 详细技术方案

### 3.1 整体框架

GR2 的整体框架包含三个串联的训练阶段，形成完整的三阶段训练管道：

**第一阶段：基于语义 ID 的中期训练**

- 输入：预训练学生 LLM（如 Qwen3-8B）、非语义物品 ID
- 过程：使用 RQ-VAE 分词器将物品文本特征编码为语义 ID 序列，在语义 ID 和自然语言混合数据上进行多任务中期训练
- 输出：理解语义 ID 的基础 LLM 模型

**第二阶段：推理轨迹生成与监督微调**

- 输入：中期训练后的 LLM、更大规模的教师 LLM（如 Qwen3-32B）
- 过程：通过精心设计的提示工程引导教师 LLM 生成推理轨迹，使用拒绝采样过滤低质量轨迹，然后用筛选后的轨迹对学生 LLM 进行 SFT
- 输出：具备基础推理能力的学生 LLM

**第三阶段：DAPO 强化学习优化**

- 输入：SFT 后的学生 LLM、重排奖励函数
- 过程：使用 DAPO 算法进行策略优化，奖励函数包含排序奖励和条件格式奖励
- 输出：最终的重排模型

### 3.2 关键模块详解

#### 模块一：RQ-VAE 分词器与语义 ID 生成

**作用**：将物品的文本特征转换为紧凑的离散符号表示，解决工业系统中海量物品 ID 的可扩展性问题。

**技术细节**：

给定物品的文本特征 x，分词器将其映射为离散整数序列：

$$
\text{Tokenizer}(x) = (z_1, z_2, ..., z_K), \quad z_k \in \{1, ..., C_k\}
$$

其中 C_k 是第 k 层码本的基数（Cardinality）。分词器的核心是残差量化变分自编码器（RQ-VAE），具体流程如下：

1. 文本编码器产生连续嵌入：h = f_enc(x), h ∈ R^d
2. 初始化残差：r_1 = h
3. 对 k=1,...,K 执行残差量化：
   - 最近邻量化：z_k = arg min_j ||r_k - e_j^(k)||²
   - 更新残差：r_{k+1} = r_k - q_k（其中 q_k = e_{z_k}^(k)）

**码本均衡技术**：

为防止码本坍缩（仅部分码本条目被使用），论文采用五种互补技术：

1. **RQ-K-Means 初始化**：使用 k-means++ 对残差进行聚类初始化码本，而非随机初始化
2. **EMA 码本更新**：使用指数移动平均更新码本，衰减率 γ ∈ [0.95, 0.99]，提供更稳定的学习
3. **多样性损失**：鼓励均匀使用码本条目
4. **死码重置**：连续 τ 批次未使用的码本条目被重新分配给重建误差最大的样本
5. **随机最后层级**：在推理时对最后 M 层使用随机分配，交换重建保真度以保证唯一性

#### 模块二：推理轨迹生成器

**作用**：生成高质量、分层级的推理轨迹，用于培养 LLM 的重排推理能力。

**技术细节**：

论文提出两种推理轨迹生成策略：

**目标采样（Targeted Sampling）**：

$$
\tau \sim P_\theta(\cdot | P_{targeted}([s_{v1}, ..., s_{vk}], [s_{y1}, ..., s_{yc}], s_{vn+1}))
$$

其中 P_targeted 构建提示查询目标物品的推荐理由。由于包含真实标签，生成结果总是有效的推荐理由，但可能产生幻觉。

**拒绝采样（Rejection Sampling）**：

$$
(\tau, \hat{s}_{yc}) \sim P_\theta(\cdot | P_{rejection}([s_{v1}, ..., s_{vk}], [s_{y1}, ..., s_{yc}]))
$$

约束条件：\hat{s}_{yc} = s_{vn+1}，即持续采样直到预测的目标物品与真实标签匹配。

**提示设计五原则**：

1. 具体的系统角色和重排任务定义
2. 协作式上下文呈现（同时呈现用户历史和完整候选集）
3. 领域知识提示（引入顺序购买模式等启发式知识）
4. 输出约束作为关键指南（要求引用物品的 SID）
5. 结构化多步推理格式

#### 模块三：DAPO 强化学习优化器

**作用**：在 SFT 基础上进一步优化推理过程和最终排序质量。

**技术细节**：

**排序奖励函数**：

$$
R_{rank} = \frac{r_D^{sv_{n+1}} - r_o^{sv_{n+1}}}{|D|}
$$

其中 r_D^{sv_{n+1}} 和 r_o^{sv_{n+1}} 分别表示目标物品在预排序列表和重排序列表中的排名。

**条件格式奖励**：

$$
R = \begin{cases}
R_{rank} + \alpha R_{fmt}, & \text{if } R_{rank} > 0 \text{ or } r_D^{sv_{n+1}} = 1 \\
R_{rank}, & \text{otherwise}
\end{cases}
$$

条件奖励设计用于缓解奖励黑客：模型倾向于保留原始排序以获得格式奖励。条件设置确保只有在真正改善排序或原始排序已最优时才给予格式奖励。

**DAPO 优化目标**：

$$
J_{DAPO}(\theta) = E_{(q,D) \sim D, \{o_i\}^G_{i=1} \sim \pi_{\theta_{old}}(\cdot|q)} \left[ \frac{1}{PG} \sum_{i=1}^G \frac{1}{|o_i|} \sum_{i=1}^G \sum_{t=1}^{|o_i|} \min\left(r_{i,t}(\theta) \hat{A}_{i,t}, \text{clip}(r_{i,t}(\theta), 1-\varepsilon_{low}, 1+\varepsilon_{high}) \hat{A}_{i,t}\right) \right]
$$

其中 G 是每批采样的输出数量，ε_low 和 ε_high 分别控制下界和上界的裁剪范围。

### 3.3 训练策略与优化

**SFT 损失函数**：

为保持排序性能同时启用推理能力，论文对推理和排序 token 分别设置损失权重：

$$
L_{SFT} = -\lambda_r \sum_{i=1}^M \log P(r_i | P, r_{<i}) - \lambda_o \sum_{j=1}^T \log P(o_j | P, \tau, o_{<j})
$$

其中 λ_r < λ_o 平衡推理流畅性和排序准确性。

**多任务中期训练**：在语义 ID 和世界知识数据混合上进行多任务训练，包括物品对齐等任务。

### 3.4 推理/部署策略

推理流程遵循三阶段管道的最终输出：给定用户购买历史和预排序候选集，模型生成结构化的推理轨迹和重排序列表。输出采用 JSON 格式，便于解析和评估。

## 4. 实验设计与结果分析

### 4.1 实验设置

**数据集**：Amazon Review 数据集（Beauty 和 Sports）

| 数据集 | 用户数 | 物品数 | 平均序列长度 |
|--------|--------|--------|--------------|
| Beauty | 22,363 | 12,101 | 8.87 |
| Sports | 35,598 | 18,357 | 8.32 |

**评估指标**：Recall@K、NDCG@K、碰撞率/唯一性率

**Baseline 方法**：
- OneRec-Think（ORT）：当前最强的 LLM 生成式推荐基线
- Pre-rank（MTL/STL）：仅使用中期训练模型的预排序结果
- SFT-variants：不同推理轨迹生成策略的 SFT 模型
- RL-variants：不同设置下的 RL 优化模型

### 4.2 主实验结果

**表 5：Amazon Beauty 数据集重排性能对比**

| Methods | recall@1 | recall@5 | recall@9 | ndcg@5 | ndcg@10 |
|---------|----------|----------|----------|--------|---------|
| Pre-rank (MTL) | 0.2892 | 0.7227 | 0.9534 | 0.5101 | 0.5997 |
| RL-rejection-KP | **0.2977** | **0.7460** | 0.9563 | **0.5234** | **0.6050** |

**关键发现**：

1. **推理轨迹质量的关键作用**：在 Beauty 数据集上，使用分层物品信息的拒绝采样（RL-rejection-KP）始终优于零样本推理（RL-zeroshot），在 recall@1 上相对提升 3.00%，在 recall@5 上提升 3.30%，在 ndcg@5 上提升 2.60%。

2. **RL 进一步增强推理激活模型**：在 Sports 数据集上，RL-targeted-KP 相比预排序基线在 recall@1 上提升 0.24%，在 ndcg@5 上提升 0.13%，表明策略优化可以精炼推理过程以更好对齐排序目标。

3. **SFT 不足以实现最佳重排**：虽然 SFT 学习了高质量、连贯的推理轨迹，但并不一致地转化为改进的重排性能，在某些情况下甚至降低 recall@1。这凸显了推理质量与排序最优性之间的不匹配，以及 RL 显式优化推理动作空间的必要性。

### 4.3 消融实验

**SID 唯一性消融（表 2）**：

| 技术组合 | 唯一性率 |
|----------|----------|
| 无 EMA 更新（基线） | 21.39% |
| EMA 更新 | 97.50% (+66.2%) |
| EMA + 随机最后层级 | 99.98% |
| 所有技术 | 99.98% |

关键发现：EMA 更新是防止码本坍缩的关键技术，使唯一性率平均提升 66.2%。随机最后层级显著提升唯一性，所有达到 ≥99% 唯一性的配置都使用此技术。

**代码本均衡技术消融（表 3）**：

| 配置 | Recall@5 | Recall@10 | NDCG@5 | NDCG@10 |
|------|----------|-----------|--------|---------|
| 无对比损失 | 0.0204 | 0.0314 | 0.0131 | 0.0167 |
| 有对比损失 | **0.0227** | **0.0367** | **0.0145** | **0.0190** |

虽然对比损失对唯一性有负面影响（-13.2%），但它一致提升下游推荐性能，最佳配置达到 Recall@10 0.0367 和 NDCG@10 0.0190。

**中期训练结果（表 4）**：

| Methods | recall@5 | recall@10 | ndcg@5 | ndcg@10 |
|---------|----------|-----------|--------|---------|
| Base (ORT) | 0.0460 | 0.0654 | 0.0314 | 0.0377 |
| tokenization enhancement | 0.0491 | 0.0695 | 0.0328 | 0.0393 |
| Base+IA (ORT) | 0.0532 | 0.0735 | 0.0342 | 0.0471 |
| Mid-Training w/ Single-task | **0.0564** | 0.0744 | **0.0406** | 0.0467 |
| Mid-Training w/ Multi-task | 0.0561 | **0.0774** | 0.0396 | 0.0467 |

分词器增强alone在所有指标上相比 ORT Base 取得一致提升，相对增益分别为：recall@5 +6.7%，recall@10 +6.3%，ndcg@5 +4.5%，ndcg@10 +4.2%。

### 4.4 其他分析

**案例研究**：

论文提供了详细案例分析，展示模型如何通过分层推理逐步推导用户下一个购买意向。在给定 Pureology 洗发水和护发素购买历史的情况下，模型正确识别用户偏好保湿产品，并通过候选集中的补水产品套装进行匹配。

## 5. 关键结论与 Takeaway

### 论文核心结论评估

1. **GR2 成功超越 OneRec-Think 基线**：声称的 2.4% Recall@5 和 1.3% NDCG@5 提升在 Beauty 和 Sports 数据集上都得到验证，实验证据充分。

2. **三阶段训练管道的必要性**：消融实验表明，每个阶段都对最终性能有贡献，完整的三阶段管道实现最佳效果。

3. **推理轨迹质量的决定性作用**：拒绝采样 + 领域知识提示（KP）组合始终优于其他配置。

4. **RL 优化的不可或缺性**：SFT 虽然能生成连贯推理，但不直接优化重排目标，RL 是将推理能力转化为排序改进的关键。

### 最有价值的 Takeaway

1. **码本均衡的 EMA 更新是关键**（可信度：高）：消融实验明确显示 EMA 更新使唯一性率从 21% 提升至 97%，是防止码本坍缩的最关键技术。

2. **条件可验证奖励有效缓解奖励黑客**（可信度：高）：实验表明条件奖励设计显著优于朴素组合奖励，避免模型通过保留原始排序作弊。

3. **拒绝采样优于目标采样**（可信度：高）：虽然目标采样保证答案正确，但拒绝采样通过验证机制产生更真实、更少幻觉的推理轨迹。

4. **多步推理格式对推理质量至关重要**（可信度：中）：提示设计中的结构化多步推理格式是引导模型生成高质量推理的关键，但具体格式对性能的影响未做完整消融。

5. **领域知识提示增强推理能力**（可信度：中）：引入顺序购买模式等启发式知识可提升推理质量，但在 Sports 数据集上提升有限。

## 6. 局限性与开放问题

### 方法局限

1. **仅在两个电商数据集验证**：论文仅在 Amazon Beauty 和 Sports 数据集上实验，未验证在更多样化场景（如新闻推荐、视频推荐）中的泛化能力。

2. **教师-学生 LLM 规模差距**：使用 Qwen3-32B 生成训练数据，蒸馏到 Qwen3-8B，规模差距可能限制学生模型完全继承推理能力。

3. **固定候选集大小**：实验采用 K=10 的固定候选集大小，未探索不同候选集规模对性能的影响。

### 实验局限

1. **仅使用离线指标评估**：推荐系统的真实价值最终体现在线上业务指标（如点击率、转化率），论文缺乏在线实验验证。

2. **仅使用 Amazon 数据集**：虽然 Amazon Review 是推荐研究的常用基准，但其数据分布可能无法代表所有推荐场景。

### 工业落地挑战

1. **推理延迟**：LLM 推理的计算成本远高于传统重排模型，在高 QPS 场景下可能面临延迟挑战。

2. **大规模物品库处理**：虽然语义 ID 解决了词汇表膨胀问题，但工业系统中数十亿物品的语义 ID 生成和维护仍需大量工程投入。

3. **数据分布偏移**：模型在用户行为分布发生显著变化时（如促销季、新品上架）的适应能力存疑。

### 开放问题

1. **RL 训练的稳定性**：DAPO 等 RL 算法对超参数敏感，如何在工业环境中稳定训练仍需探索。

2. **多模态物品表示**：当前仅使用文本特征，如何有效融合图像、视频等多模态信息是未来方向。

3. **可解释性与隐私的平衡**：推理轨迹展示了模型的决策逻辑，但可能暴露用户隐私信息。

## 7. 应用价值分析

### 技术可借鉴性

1. **语义 ID 编码方案**：GR2 的五 种码本均衡技术可直接借鉴到任何使用 RQ-VAE 的生成式推荐系统。

2. **条件奖励设计**：针对奖励黑客的条件奖励机制是 RL 应用中的重要创新，可广泛应用于其他需要可验证奖励的场景。

3. **提示工程模板**：五原则提示设计为构建领域特定推理系统提供了可迁移的设计指南。

### 适用场景

- **电商推荐重排阶段**：GR2 的设计直接针对电商场景的顺序购买预测，在该场景下效果最佳
- **需要可解释推荐的系统**：推理轨迹提供了透明的决策依据，适用于对可解释性有要求的场景
- **具备一定 LLM 推理能力的系统**：需要 Qwen3-8B 及以上级别的 LLM 推理能力支持

### 改造建议

若要在现有推荐系统中落地 GR2：

1. **离线推理可行性评估**：在候选集大小为 10 时测试 LLM 推理延迟，确保满足业务延迟要求
2. **增量训练替代全量训练**：基于已有推荐 LLM 进行增量训练，而非从头训练
3. **A/B 测试验证**：在离线指标提升后，通过 A/B 测试验证对核心业务指标的影响

### ROI 评估

**ROI：高**

理由：GR2 的核心技术（如语义 ID、条件奖励）在离线实验中验证有效，主要创新点清晰，实现路径明确。虽然 LLM 推理成本较高，但在重排阶段（候选集已较小）的影响相对可控，可通过模型量化和批处理推理优化成本。

## 8. 关键引用与延伸阅读

### 1. TIGER: Recommender Systems with Generative Retrieval

- 作者：Rajput et al., 2023
- 引用：NeurIPS 2023
- 推荐理由：开创性引入语义 ID 技术的里程碑工作，为 GR2 的语义 ID 模块奠定基础
- 与本文关系：GR2 直接基于 TIGER 的语义 ID 框架进行改进

### 2. OneRec-Think: In-text Reasoning for Generative Recommendation

- 作者：Liu et al., 2025
- 引用：arXiv preprint
- 推荐理由：GR2 的核心 baseline，首次将链式思维推理引入生成式推荐
- 与本文关系：GR2 的中期训练策略直接继承自 OneRec-Think，并在此基础上增加 RL 优化

### 3. PLUM: Adapting Pre-trained Language Models for Industrial-scale Generative Recommendations

- 作者：He et al., 2025
- 引用：arXiv preprint
- 推荐理由：Google 在 YouTube 推荐系统上的工业级实践，提供规模化部署的经验参考
- 与本文关系：技术路线相似，都采用中期训练对齐 LLM 与推荐领域

### 4. DAPO: An Open-source LLM Reinforcement Learning System at Scale

- 作者：Yu et al., 2025
- 引用：arXiv preprint
- 推荐理由：GR2 第三阶段采用的 RL 算法来源，详细的技术实现参考
- 与本文关系：GR2 直接采用 DAPO 算法并针对重排任务重新设计奖励函数

### 5. REARANK: Reasoning Re-ranking Agent via Reinforcement Learning

- 作者：Zhang et al., 2025
- 引用：EMNLP 2025
- 推荐理由：搜索领域的推理增强重排工作，提供跨领域视角
- 与本文关系：同属推理增强重排方向，但面向搜索文档而非推荐物品

### 6. DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models

- 作者：Shao et al., 2024
- 引用：arXiv preprint
- 推荐理由：GRPO 算法（原 DAPO 基于此改进）的来源工作，RL 数学推理领域的突破
- 与本文关系：GR2 采用的策略优化算法源自 GRPO 及其后续改进

### 7. R⁴ec: A Reasoning, Reflection, and Refinement Framework for Recommendation Systems

- 作者：Gu et al., 2025
- 引用：RecSys 2025
- 推荐理由：推荐系统中引入迭代反思机制的工作，提供另一种推理增强思路
- 与本文关系：同属推理增强推荐方向，但采用迭代反思而非单步推理
