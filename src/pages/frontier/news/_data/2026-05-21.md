    desc: "[Ziliang Wang / Gaoyun Lin / Weijie Bian / Jian Dong](https://arxiv.org/html/2604.12234v3) 等 Shopee 团队的 [UniRec](https://arxiv.org/abs/2604.12234) v3（5/20 更新）正面回答了 *生成式推荐能否赶上判别式推荐的表达能力* 这一长期争论：① 作者用 **贝叶斯定理** 给出结构性证明——*按 p(y|f,u) 排序* 等价于 *按 p(f|y,u) 排序*，后者可按 item 特征自回归分解，**一个具有完整特征访问权的生成模型与判别式排序模型在表达力上等价**，二者之间的实际差距完全源自 *特征覆盖不完整*，而不是某种『结构性劣势』；② 因此提出 **Chain-of-Attribute（CoA）** —— 在每个 SID 序列前缀注入结构化属性 token（**类目 / 卖家 / 品牌**），形成 *speculate-then-refine* 的解码范式：模型先生成结构化属性，再在该条件下生成 SID；理论上每步熵 *H(s_k|s_<k, a) < H(s_k|s_<k)*，搜索空间被显著压缩、beam search 也更稳定；③ 工程层面同步解决两个落地痛点 —— **Capacity-constrained SID**（带曝光权重的容量惩罚，抑制 token 坍缩与马太效应）+ **Conditional Decoding Context**（Task-Conditioned BOS + hash-based Content Summaries），并用 *RFT + DPO 联合训练* 把模型对齐到业务目标。**实验**：相比最强 baseline *HR@50 +22.6% 整体 / +15.5% 高客单订单*；**Shopee 线上 A/B**：**PVCTR +5.37% / 订单 +4.76% / GMV +5.60%** 全面正向。值得关注的原因：① 这是 6 周内继 [TIGER](https://arxiv.org/abs/2305.05065) / [PRISM](https://arxiv.org/abs/2601.16556) / [DiGeR](https://arxiv.org/abs/2601.19711) / [RAGR](https://arxiv.org/abs/2605.17267) / [DIG](https://arxiv.org/abs/2605.14853) 之后，**第一次给出『生成式推荐的表达力理论上限』** 的形式化证明 —— 把 GR 与判别式排序的对比从『工程比较』拉回 *贝叶斯框架* 严格表达；② Chain-of-Attribute 与 5/17 RAGR『把 review SID 喂进 GR 自回归』+ 5/18 SAPO『把 RL credit 切到 SID-token 级』+ 5/20 GUIDE『把 DT 当 GR 策略 backbone』形成本周『**SID 已不再只是 item 的语义编码，而是 GR 系统中所有信号的统一通用 token**』的同向证据；③ Shopee 是继 *京东 GenRec / 阿里妈妈 GUIDE / 字节 HyFormer / Meta Adaptive Ranking Model* 之后，**6 周内第五家工业 GR 给出订单级正向 A/B 的电商平台**，2026 H2 的 GR 工业化大概率不再是 *能否* 问题、而是 *如何最快上线* 问题。"

    desc: "[Yangchen Zeng](https://www.arxiv.org/abs/2605.05249) 等 6 位作者的 TriAlignGR 是本周第二篇正面解决 *『SID 还原能力不够 / SID 表示静态』* 的工作（前一篇是 5/18 [Ghost](https://arxiv.org/abs/2605.16825) + MAIL）。作者首次形式化 **SID 两大底层问题**：① **SID Content Degradation (SCD)** —— 级联编码 + residual quantization 会丢掉多模态与 interest-level 语义；② **SID Semantic Opacity (SSO)** —— 模型自回归生成 SID 但 *不真正理解* 其语义，导致 hallucination 与泛化弱。**三件改造同时上**：① **Cross-Modal Semantic Alignment (CMSA)** —— 同时用 *VLM 生成的图像描述文本* 与 *多模态 embedding* 把视觉直接编入 SID，让 SID 天然带多模态语义；② **Multimodal Deep Interest Mining (MDIM)** —— 用 LLM Chain-of-Thought 抽取 *latent user intent*（例如『*productivity-focused lifestyle*』）替代浅层属性；③ **Triangular Multitask (TMT)** —— 八个补全任务在单一自回归 loss 下联合训练，包含两个新视觉-语义任务 *VisDesc→SID / VisDesc→Title* 完成 *SID-Text-Image* 三角闭环。值得关注的原因：① *SCD / SSO* 第一次给 SID 的痛点起了正式名字，跟 *『SID 不是 item ID 的语义编码，而是 GR 系统所有信号的统一通用 token』* 这一本周大趋势完美对接 —— *Visual / Text / Behavioral* 三模态信号都该流进 SID；② 这是 6 周内继 [CapsID](https://arxiv.org/abs/2605.05096)（软路由变长 SID）、[SID-MLP](https://arxiv.org/abs/2605.12617)（按 SID 层级对齐 head）、[AsymRec](https://arxiv.org/abs/2605.14512) 之后，*SID 表达能力研究* 的第四块拼图；③ 对工业团队的直接意义：CMSA 的两个组件（*VLM 描述 + 多模态 embedding 双源融合*）几乎可以零侵入挂到 TIGER / [HSTU](https://arxiv.org/abs/2402.17152) / [PRISM](https://arxiv.org/abs/2601.16556) 的码本生成阶段，2026 H2 多模态 SID 极可能成为新一代 GR 默认件。"
