    desc: "5/21 提交，给 conversational recommender system 提出了第一个『完全生成式』方案。当前 CRS 主流仍是 modular pipeline：dialog encoder 出 query → item embedding 上最近邻检索 → 占位符替换塞回响应模板，存在 decoupled optimization 与 limited knowledge integration 两个老问题。GenCRS 把 item 表征成结构化 Semantic ID 直接进生成空间，让 LLM 同时 next-token 预测 item ID 与 dialog response；同时引入 structured generation paradigm 把会话推荐显式分解为有序决策序列——先预测 response intent + recommendation target，再生成 conditioned response。配合 constrained decoding 保证 faithful item 生成，Recall@1 较强 baseline 最高 +29%、对话质量也稳。值得关注的原因：CRS 一直是『为什么 LLM 推荐到现在还没真正接管 modular pipeline 的最后一公里』，GenCRS 给出的『先决策、后实现』分解结构，对生成式推荐 + 对话融合是关键的工程范式补丁。"
