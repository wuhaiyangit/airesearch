## 一、推荐系统：生成式召回从「能用」走向「好用」

今天 arXiv cs.IR 的更新堪称一次小型「生成式推荐周」——一口气出现了 [UniVA](https://arxiv.org/abs/2605.05803)、[CapsID](https://arxiv.org/abs/2605.05096)、[TriAlignGR](https://arxiv.org/abs/2605.05249)、[Expressiveness Limits](https://arxiv.org/abs/2605.06331) 等多篇方向各异但同主题的工作，配合 [Bayesian List-wise Alignment](https://arxiv.org/abs/2605.04559) 在偏好对齐侧的进展，整个生成式推荐（Generative Recommendation, GR）的工程链条正在被一寸寸补齐。

**值得关注的原因**：过去一年，OneRec、TIGER、HSTU 把 GR 推到了「能上线」的状态；而 5 月这一波工作则把战场从"能跑"切到"工业级好跑"——

1. **价值对齐被首次写进 GR 链路**。阿里妈妈的 [UniVA](https://arxiv.org/abs/2605.05803) 是这周最具工业落地价值的论文之一。它指出此前的 GR pipeline 几乎都是「语义中心」的：tokenizer 学的是语义 ID，解码学的是语义连续性，serving 阶段才硬贴一层 ECPM 排序。在广告场景下这套范式天然漏价值——因为 token 概率与商业价值并不同分布。UniVA 的解法是把 ECPM/eCPC 信号显式注入到三处：tokenization 时对高价值 item 给更密的 SID 容量、解码时引入价值校准 logit、serving 时用价值约束的 beam search。报告显示线上消耗 +约 6%，这是生成式广告召回首次被验证可以"语义+价值"端到端联合优化。

2. **Tokenizer 才是真正的瓶颈**。[CapsID](https://arxiv.org/abs/2605.05096) 的核心论断很直白——GR 的瓶颈不在 Transformer，而在 tokenizer：RQ-VAE 在每一层都做硬最近邻分配，必然在簇边界把多面语义压平，并把早期错误一路传到后面的位置。CapsID 用胶囊式软路由 + 变长 SID 替代固定层数的硬量化，思路与最近的 R3-VAE、DeepInterestGR 一脉相承，背后是同一个共识：**SID 不是免费午餐，它是 GR 性能上界的隐形天花板**。这条线值得搜推广所有团队重点跟进。

3. **理论也在补课**。[Expressiveness Limits of Autoregressive Semantic ID Generation](https://arxiv.org/abs/2605.06331) 第一次给出 GR 模型的理论表达力上界——把 token-by-token 解码看作在 SID 解码树上的路径搜索，证明候选集合的可达组合数受树结构严格约束。这意味着：盲目堆 SID 长度并不能换来线性的表达力增长，**SID 设计本身需要被作为一个独立的研究方向**，而不是依附于编码器。

工业侧，字节跳动 [MixFormer](https://zhuanlan.zhihu.com/p/2014019424219324692)、UG-Sep 等架构在抖音 / 抖音极速版的全量部署同样值得记一笔——它们解决的是「序列建模 + 稠密特征交互」在固定算力下的零和博弈问题，给出了 36% FLOPs 降低 + 30%+ 推理延迟降幅的硬数据。在生成式召回逐渐统一离线训练范式的同时，**线上 serving 侧的算力 codesign 仍然是大厂最重要的护城河**。

## 二、大语言模型：开源前二易主，国产模型第一次让 GPT-5 看不到尾灯

5 月初最大的产业事件，是 [Kimi K2.6](https://www.moonshot.cn/blog/k2-6) 与 [DeepSeek V4](https://api-docs.deepseek.com/news/news250424) 两家国产开源模型在 [Artificial Analysis](https://artificialanalysis.ai/) 智能指数和 [SWE-Bench Pro](https://www.swebench.com/) 上同时压过 GPT-5.4——这是国产开源模型第一次在硬核评测里把 GPT 系列按在身后。

- **Kimi K2.6**：1T 参数 MoE / 32B 激活，SWE-Bench Pro **58.6**（GPT-5.4 57.7 / Claude Opus 4.6 53.4 / Gemini 3.1 Pro 54.2），AIME 2026 数学 96.4，最高支持 300 个子 Agent 并行 + 4000 协作步骤，长程编码可连续运行 13 小时。
- **DeepSeek V4**：1.6T 总参数 / 49B 激活 / 1M 上下文，输出 \$3.48/M token；技术看点是混合注意力 **CSA + HCA** + mHC（流形约束超连接）残差 + Muon 优化器，KV Cache 与长上下文吞吐都被推到了一个新的台阶。

**值得关注的原因**：从 2025.01 的 R1 / K1.5、2025.02 的 NSA / MoBA、2025.04 的 Prover 系列，到 2026.04-05 的 V4 / K2.6，DeepSeek 与 Kimi 这种「同周出牌、互相校准」的节奏已经形成事实上的国产开源双子星格局。开源模型的真实调用量也在重排——OpenRouter 统计中两家公司同时挤入全球 TOP5。对推荐系统从业者，这意味着两件事：第一，**长上下文 + 低输出价格** 的曲线让"用 LLM 重排 / 重写召回"的工业方案 ROI 显著好转；第二，国产推理基础设施（vLLM / SGLang / 真武 PPU 等）在两周内完成 V4 / K2.6 适配，长程 Agent 与长上下文推理的"基础设施红利"开始外溢到推荐场景。

OpenAI 这边节奏并不慢：4 月 23 日 GPT-5.5 旗舰、4 月 30 日 GPT-5.5-Cyber 网络安全特化预告、5 月 6 日 [GPT-5.5 Instant](https://openai.com/index/gpt-5-5/) 接管 ChatGPT 默认模型、5 月初 GPT-Realtime-2 实时语音上线。Instant 路线说明 OpenAI 正在把"低延迟 + 个性化"做成一条独立的产品族——这恰恰是推荐 / 广告场景最关心的两个维度。

Anthropic 的故事同样硬核：[Q1 ARR 突破 300 亿美元](https://www.anthropic.com/news/q1-2026-update)，按年化口径季度环比增长 80 倍，并与 SpaceX 锁定 22 万 GPU 算力大单。算力账单压顶之下，「商业化先行 + 算力联盟」成为头部模型公司的统一动作。

## 三、推荐论文速读

- [Multi-LLM Token Filtering and Routing for Sequential Recommendation](https://arxiv.org/abs/2604.18200v1)：用多 LLM 路由的 token 过滤替代单模型推理，在长行为序列上找到了语义保真与延迟之间的新折衷点。
- [SRBench](https://arxiv.org/abs/2604.09553)：覆盖 8 类任务的 LLM 序列推荐综合基准，把"指令推荐 / 工具调用 / 链式重排"统一到一个评测口径，是接下来 LLM4Rec 论文绕不开的对照。
- [GFlowGR](https://arxiv.org/pdf/2506.16114) / [NEZHA](https://arxiv.org/pdf/2511.18793)：阿里妈妈搜索广告的姊妹篇——前者用 Generative Flow Networks 微调 GR，后者给出"零牺牲、高速度"的解码架构，配合今天的 UniVA 形成完整的"价值-训练-解码"三件套。
