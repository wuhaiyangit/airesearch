    link: "https://arxiv.org/abs/2606.20554"

    desc: "arXiv 2606.20554(6/18提交)，Ruizhong Qiu / Yinglong Xia / Dongqi Fu / Hanqing Zeng / Ren Chen / Xiangjun Fan / Hong Li / Hong Yan / Hanghang Tong(Meta + UIUC，9位作者，Hong Li/Hong Yan为RankGraph-2核心作者)。核心问题：生成式推荐的核心在于Item Tokenization——将物品语义与推荐模型桥接。但现有方法难以同时有效组织和注入复杂的用户行为上下文与物品语义上下文：图序列化方法存在可扩展性问题或仅利用局部图信息；语义分词方法依赖启发式缺乏显式监督信号，导致语义表示不精确。G2Rec提出统一框架：(1)基于全局图的用户共参与(co-engagement)建模，从全局用户-物品交互图中提取用户兴趣原型，而非仅依赖局部序列；(2)将图结构信息注入语义分词过程，构建具有显式监督的语义Tokenization；(3)设计新的序列格式交替插入物品token和兴趣原型token，使生成式推荐器在解码每一步都能感知当前用户兴趣状态转移。无需真实用户兴趣标签即可捕获全局且语义接地的兴趣原型。已在Meta多个产品线完成在线部署，公开数据集实验亦全面超越现有方法。值得关注：G2Rec与同期RankGraph-2(图检索)形成Meta推荐团队的完整闭环——RankGraph-2解决十亿节点图检索的工程效率，G2Rec解决生成式推荐中用户兴趣上下文的建模质量。核心作者重叠(Hong Li, Hong Yan)暗示这两个系统在Meta内部可能已实现协同部署。对GR领域：G2Rec首次将全局图结构显式注入GR的tokenization过程——此前GR主要依赖RQ-VAE或TIGER式层次聚类做tokenization，G2Rec证明全局协同结构可以通过兴趣原型token的形式直接参与自回归生成。"

    link: "https://arxiv.org/abs/2606.19635"
    source: "Google"
    category: "推荐系统"
    type: "技术报告"
    desc: "arXiv 2606.19635(6/17提交)，Xilun Chen / Shao-Chuan Wang / Baykal Cakici / Lukasz Heldt / Lichan Hong / Raghu Keshavan / Aniruddh Nath / Li Wei / Xinyang Xi(Google 9位作者，Lichan Hong为Google推荐领域资深研究员)。核心问题：大规模推荐模型(Large Recommendation Models, LRMs)在工业推荐中展现出强大能力，但如何将传统推荐信号(协同信号、统计特征、上下文特征等异构信号)全面高效整合到Transformer架构中仍是重大挑战。传统方法将这些信号文本化或创建离散表示，会导致Prompt长度爆炸、内存占用过大、计算开销过高。Token Factory提出将传统信号转化为soft tokens——通过可学习的压缩网络将异构输入特征映射为少量软token，直接被LRM处理。这一方法实现：(1)异构输入特征的高效整合与压缩；(2)防止Prompt长度爆炸；(3)增强模型性能。已在生产级推荐环境中验证有效性。值得关注：Token Factory代表Google在LRM方向的工程实践——不是将推荐任务转化为NLP任务(textualization)，而是将传统推荐信号以token的形式原生注入Transformer。这与Meta的G2Rec(图结构→兴趣原型token)形成有趣对照：两者都在解决'如何让Transformer原生消化推荐信号'的问题，但G2Rec从图协同方向切入，Token Factory从异构特征压缩方向切入。对推荐系统工程师：soft token方案提供了一种将现有特征工程资产平滑迁移到LRM架构的路径，无需重构整个特征体系。"

    desc: "KDD 2026 ADS Track Accepted，arXiv 2606.19658(6/18提交)，Gaode Chen / Shicheng Wang / Shikun Li / Rui Huang / Xinghua Zhang / Yunze Luo / Shipeng Li / Shiming Ge / Ruina Sun / Yinjie Jiang / Jun Zhang(快手 + 港浸会 + 北大 + 南大 + 中科院信工所，11位作者)。核心洞察：隐式反馈推荐系统中冷启动物品更容易受噪声样本(点击诱导/位置偏置)污染，但已有去噪方法(基于高loss值启发式)在冷启动场景下适应性有限。DIF(Denoising Implicit Feedback)提出模型无关的冷启动去噪框架：(1)利用用户内容偏好的稳定性，通过内容相似的暖物品推断冷物品的伪标签(pseudo-labels)；(2)基于内容相似度建模伪标签置信度，温度系数+softmax聚合多个伪标签；(3)结合相对熵和冷启动状态显式估计噪声标签的不确定性，自适应引导伪标签对噪声标签的校正力度。理论证明：在Holder连续性和暖物品密度充分条件下，伪标签误差有界。已部署十亿用户级短视频平台快手，冷启动场景商业指标(有效观看/观看时长)显著提升。值得关注：DIF与同期Meta的G2Rec形成互补——G2Rec解决GR中用户兴趣上下文建模，DIF解决传统推荐中冷启动噪声。两者都强调利用全局协同信息(G2Rec用图、DIF用暖物品邻域)来增强局部信号不足的场景。对工程实践：DIF的ANN检索内容相似暖物品+实时Embedding Service更新协同表示的工业管线设计具有直接参考价值。"
