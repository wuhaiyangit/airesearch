    link: "https://arxiv.org/abs/2605.15203"
    source: "蚂蚁 / 上海交大 / 复旦 / arXiv"

    desc: "[Jinze Wang / Tiehua Zhang / Xingjun Ma / Zhu Sun](https://arxiv.org/abs/2605.15203) 等蚂蚁 + 上海交大 + 复旦联合团队 5/15 提交的 Agent4POI 是第一篇正面回答 *LLM Agent 应该在推荐时刻（recommendation time）干什么* 的论文。核心论点：传统多模态推荐对每个 POI 预先编码出一个静态 embedding，*但同一家咖啡店在『周一独自办公』和『周五晚朋友聚会』下的 affordance 完全不同*——作者形式化地证明了：*在标准 bilinear scoring 下，没有任何 pre-computed encoder 可以满足 context-sensitive ranking*，从而得出『*item 侧表示必须在 inference time 生成*』的结论。Agent4POI 的四阶段 LLM Agent 流水线：① 把情境上下文翻成 *context-conditioned affordance queries*；② 跨图像 / 评论 / 元数据三模态做五步 chain-of-thought；③ 形成 *uncertainty-aware affordance representation*（与 Gibsonian affordance theory 对齐）；④ 用语义缓存做低延迟排序，与用户偏好对齐。三 POI benchmark 三种评估配置（standard / cold-start / context-shift）下：相比最强 baseline 平均 **+23.2%**，*context-shift 下只跌 7.5% vs baseline 跌 16-17%*，*cold-start 下相比最强 content-based baseline 提升至 2.4×*，**ID-based 方法在 cold-start 下完全失效**。值得关注的原因：① 这是 *『推荐时刻 LLM Agent reasoning』* 第一篇形式化论文，与同周 [SAPO](https://arxiv.org/abs/2605.17648)（reasoning-GR 的 RL credit assignment）、[TwiSTAR](https://arxiv.org/abs/2605.11553)（adaptive compute）共同把 *reasoning + agentic* 推到 GR 上游；② 解决了 LLM4Rec 的一个长期痛点——*把 LLM 当成 user-side 工具* 还是 *item-side 工具*，Agent4POI 给出明确答案：*item-side affordance 现场生成* 比 *user-side 偏好抽取* 更能利用 LLM 的世界知识；③ 对生活服务（美团 / 大众点评 / 高德 / 携程）类 LBS 推荐团队，论文直接给出可复现的 4-phase agent 模板，cold-start 与 context-shift 是该领域核心痛点。"
