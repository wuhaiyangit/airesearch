    desc: "Jun Yin、Hao Chen、[Senzhang Wang](https://scholar.google.com/citations?user=2lTzFb0AAAAJ)、[Shirui Pan](https://shiruipan.github.io/)、[Chengqi Zhang](https://research-portal.uts.edu.au/en/persons/chengqi-zhang) 等中南大学 + 格里菲斯大学 + 悉尼科技大学联合团队 5/16 提交的 [Ghost](https://arxiv.org/abs/2605.16825) 把上半年 GR 工业落地之后被一笔带过的 *流行度偏置（popularity bias）* 第一次正面解剖：① 理论上证明 GR 的 popularity bias 不是来自数据分布，而是来自两个『结构性』原因——**token-level 优化的对称性缺陷**（unlikelihood-style 损失把所有非目标 token 一视同仁拉低，热门候选自然被算法奖励）+ **SID Tokenization 的同质性**（多个流行 item 在前几层码字上完全共享，模型一旦命中 head 路径就反复挑这些热门）；② 提出 **Asymmetric Unlikelihood Optimization** —— 对模型已经『过度自信』的热门 SID 路径施加更强的下行 gradient，对长尾 SID 路径反向放宽 —— 这是第一次把 *优化器层面* 的 popularity 修正写进 GR；③ **Skeleton-Founded Tokenization** 在码本生成阶段先抽出『骨架码字』把流行类目与长尾类目分开锚定，避免 codebook 在头部 item 上的过度复用。三个公开集对比 TIGER / [PRISM](https://arxiv.org/abs/2601.16556) / [DiGeR](https://arxiv.org/abs/2601.19711) / [DIG](https://arxiv.org/abs/2605.14853)，Ghost 在长尾覆盖度（Tail-Recall@10）显著上升，整体精度只有轻微回落。值得关注的原因：① 上半年 *SID-MLP*（Snap）、*TwiSTAR*、*DIG*（美团）、*AsymRec*（清华×腾讯）密集解决的是『*让 GR 更快*』，Ghost 是 6 周内第一篇正面回答『*让 GR 更公平*』的工作，把 GR 研究从 *吞吐 / 精度* 二维拉回 *吞吐 / 精度 / 公平* 三维；② 与 5/13 [百度 RAG-Enhanced 动态过期判定](https://arxiv.org/abs/2605.13052)、Meta UTIS 共同形成『**给 GR 加治理层**』的同向证据；③ 对工业团队最直接的意义：Asymmetric Unlikelihood 与 Skeleton Tokenization 两个组件都是 **plug-in 风格**，可以直接挂到 TIGER、HSTU、DIG 等现有 backbone，不需要重训。"

    desc: "[Yaochen Zhu](https://yaochenzhu.github.io/)、Liang Wu、[Liangjie Hong](https://www.linkedin.com/in/liangjiehong) 等 UVA × LinkedIn 团队 5/17 提交的 [SAPO](https://arxiv.org/abs/2605.17648)（Step-Aligned Policy Optimization）紧接 5/15 京东 [GenRec](https://arxiv.org/abs/2604.14878) 与 4 月 [F-GRPO](https://arxiv.org/abs/2605.12995) 之后第三次重写 GR-RL 的 advantage 设计：① 作者指出在 *Reasoning-based GR*（thinking block + SID 生成）这一新范式里，**outcome-reward** 只能告诉你『最终 item 是否命中』，无法告诉你『*是哪一步 SID token 出的错*』——一旦总命中失败，正确 token 与错误 token 会被同时惩罚，是当前 GR-RL 收敛不稳定的根因；② SAPO 把 *thinking block 与对应 SID token* 视为一个『推理步』，对每一步独立计算 group-relative advantage，只把这个 advantage 应用到该步对应的 thinking block + SID token 上，等价于把 GRPO 的 *response-level credit* 切到 *step-level credit*；③ 三个公开集稳定优于 outcome-reward baseline，**sparse exact-match feedback 越稀疏，提升越大**。值得关注的原因：① 这是第一篇把 *『结构化生成的 RL 目标，应该镜像 decoder 自己的输出分解』* 写进推荐系统正式形式化的工作——不是简单复用 PPO/GRPO，而是与 SID 多层码字结构对齐；② 与同周 SID-MLP 把 *『解码 head 与 SID 层级对齐』* 思路完全一致——**SID 层级结构正在变成生成式推荐工程设计的新一阶段公理**；③ 对工业 reasoning-based GR 团队（淘宝 RecGPT-Mobile、京东 GenRec、阿里 REG4Rec、字节 LASAR）的直接价值：上半年大量 reasoning-GR 反映 *RL fine-tune 在召回阶段过拟合、在排序阶段反复震荡*，SAPO 的 step-level advantage 是目前最可能直接落地的修复方案。"
