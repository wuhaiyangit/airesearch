## 多模态融合的核心问题

视觉-语言多模态融合需要解决三个核心问题：

1. **模态对齐**：如何将视觉特征和语言特征映射到同一语义空间
2. **信息融合**：如何有效整合两种模态的信息
3. **跨模态推理**：如何基于融合后的表示进行复杂推理

## CLIP：对比学习对齐

OpenAI的CLIP（Contrastive Language-Image Pre-training）通过对比学习实现视觉-语言对齐：

### 训练目标

给定 $N$ 个图文对，最大化匹配对的相似度，最小化不匹配对的相似度：

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\left[\log\frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ij}/\tau}} + \log\frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ji}/\tau}}\right]$$

### 训练数据

CLIP使用从互联网收集的4亿图文对进行训练，规模是关键。

### 零样本能力

CLIP展示了强大的零样本分类能力：将类别名称转化为文本提示（如"a photo of a {class}"），与图像特征计算相似度即可分类。

## LLaVA：视觉指令微调

LLaVA（Large Language and Vision Assistant）将视觉能力注入LLM：

### 架构设计

```
图像 → CLIP视觉编码器 → 线性投影层 → LLM Token空间
文本 → Tokenizer → LLM Token空间
                              ↓
                         LLM（LLaMA/Vicuna）
                              ↓
                           文本输出
```

### 训练阶段

**阶段一：特征对齐**
- 冻结视觉编码器和LLM
- 只训练线性投影层
- 使用图文描述数据

**阶段二：端到端微调**
- 冻结视觉编码器
- 训练投影层 + LLM
- 使用视觉指令数据

## GPT-4V的技术路线

GPT-4V（Vision）代表了多模态LLM的最高水平，其技术特点：

| 特性 | 描述 |
|------|------|
| 高分辨率支持 | 支持最高2048×2048分辨率 |
| 多图理解 | 支持在单次对话中处理多张图片 |
| 细粒度识别 | 能识别图中的文字、表格、图表 |
| 推理能力 | 支持基于图像的复杂逻辑推理 |

## 当前挑战

### 幻觉问题

多模态LLM容易产生与图像内容不符的描述，称为"视觉幻觉"。主要原因：

- 语言先验过强，忽视视觉信息
- 训练数据中存在噪声图文对
- 视觉特征提取不够精细

### 细粒度理解

对于需要精确定位的任务（如目标检测、图像分割），当前多模态LLM表现仍不理想。

## 未来方向

- **原生多模态**：不再将视觉特征"翻译"为语言，而是在统一空间中建模
- **视频理解**：从静态图像扩展到动态视频
- **3D感知**：引入深度信息和空间推理能力
